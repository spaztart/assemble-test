# Phone Input

A composite phone number input with a searchable country code dropdown and numeric input field. Supports keyboard navigation, type-ahead search, and E.164 digit validation.

## Guidelines

- Always include a label for accessibility
- The dropdown filters by country name, dial code, or ISO code
- Max 15 digits (E.164 standard) — non-digit characters are stripped
- Arrow keys navigate the dropdown; Enter selects; Escape closes
- Use error-text for validation feedback
- The component fires `change` with full value details on every edit

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | Label above the input |
| `default-country` | `string` | `'US'` | Initial ISO country code |
| `value` | `string` | `''` | Phone digits (no formatting) |
| `placeholder` | `string` | `'Phone number'` | Placeholder text |
| `error-text` | `string` | `''` | Error message below |
| `supporting-text` | `string` | `''` | Helper text below |
| `disabled` | `boolean` | `false` | Disabled state |
| `size` | `'small' \| 'medium' \| 'large'` | `'medium'` | Density variant |

| Event | Detail | Description |
|-------|--------|-------------|
| `change` | `{ value, countryCode, dialCode, countryName }` | Fired on any value change |

### Flutter

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `automationIdentifier` | `String` | required | Test automation ID |
| `label` | `String?` | `null` | Label above input |
| `defaultCountryCode` | `String` | `'US'` | Initial country |
| `defaultNumber` | `String` | `''` | Initial phone digits |
| `onChanged` | `ValueChanged<AsmPhoneputValue>?` | `null` | Value change callback |
| `size` | `AsmPhoneputSize` | `.medium` | Density |
| `enabled` | `bool` | `true` | Enabled state |
| `errorText` | `String?` | `null` | Error text |
| `supportingText` | `String?` | `null` | Helper text |
