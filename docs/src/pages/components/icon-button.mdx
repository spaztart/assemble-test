# Icon Button

Icon buttons help people take supplementary actions with a single tap. Use icon buttons for compact actions like toggling a favorite, opening a menu, or performing a delete.

## Guidelines

- Always provide a `label` for accessibility — icon buttons have no visible text
- Use `selected` for toggle states like bookmark, favorite, or pin
- Use `destructive` only for irreversible actions like delete
- Prefer `standard` variant for toolbars to reduce visual noise
- Provide a `tooltip` in Flutter for hover/long-press discoverability

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `icon` | `string` | `''` | Material Symbols icon name |
| `variant` | `standard` \| `filled` \| `tonal` \| `outline` | `standard` | The visual style |
| `size` | `huge` \| `spacious` \| `default` \| `compact` | `default` | The button size |
| `disabled` | `boolean` | `false` | Whether the button is disabled |
| `destructive` | `boolean` | `false` | Destructive/danger mode |
| `selected` | `boolean` | `false` | Toggle selected state |
| `label` | `string` | `''` | Accessible label (aria-label) |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `icon` | `Widget` | required | Icon widget to display |
| `automationIdentifier` | `String` | required | Stable ID for UI test automation |
| `onPressed` | `VoidCallback?` | `null` | Tap handler. `null` disables the button |
| `tooltip` | `String?` | `null` | Hover/long-press tooltip |
| `semanticLabel` | `String?` | `null` | Override announced label for assistive tech |
| `variant` | `AsmIconButtonVariant` | `.filled` | The visual style |
| `size` | `AsmIconButtonSize` | `.large` | The button size |
| `destructive` | `bool` | `false` | Destructive/danger mode |
