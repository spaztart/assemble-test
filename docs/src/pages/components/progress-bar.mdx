# Progress Bar

A determinate horizontal progress bar with status-based color variants. Use to show completion of downloads, scans, or multi-step workflows.

## Guidelines

- Value is always between 0 and 1 (clamped)
- Use brand status for general progress
- Use moderate (blue) for informational state
- Use critical (orange) for warnings
- Use low (green) for healthy/positive completion
- The bar is pill-shaped (border-radius 999px)
- Thick (14px) is the default; use thin (8px) for compact layouts

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `value` | `number` | `0` | Progress value (0–1) |
| `status` | `'brand' \| 'moderate' \| 'critical' \| 'low'` | `'brand'` | Color variant |
| `size` | `'thick' \| 'thin'` | `'thick'` | Height: thick=14px, thin=8px |
| `aria-label` | `string` | `'Progress, {status}'` | Accessible label |

### Flutter

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `value` | `double` | required | Fill fraction 0.0–1.0 |
| `status` | `AsmProgressBarStatus` | `.brand` | Colour ramp |
| `size` | `AsmProgressBarSize` | `.thick` | 14px or 8px tall |
| `width` | `double?` | `null` | Fixed width (null = fill parent) |
| `foregroundColor` | `Color?` | `null` | Override fill color |
| `foregroundGradient` | `Gradient?` | `null` | Override with gradient |
| `trackColor` | `Color?` | `null` | Override track color |
