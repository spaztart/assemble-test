# Snackbar

Snackbars provide brief, non-intrusive notifications at the bottom of the screen. They inform users about a process that has been or will be performed, with an optional action.

<div class="hero-preview">
  <div class="preview-row">
    <asm-button label="Show Snackbar" variant="tonal" id="hero-snackbar-trigger"></asm-button>
  </div>
</div>

<script>{`
  document.addEventListener('astro:page-load', () => {
    document.getElementById('hero-snackbar-trigger')?.addEventListener('click', () => {
      const sb = document.getElementById('global-snackbar');
      if (sb) {
        sb.setAttribute('message', 'Item has been archived');
        sb.setAttribute('action-label', 'Undo');
        sb.setAttribute('leading-icon', '');
        sb.setAttribute('duration', '4000');
        sb.open = true;
      }
    });
  });
`}</script>

## Guidelines

- Keep messages short and clear (one line preferred)
- Provide an undo action for destructive operations
- Snackbars should auto-dismiss after a few seconds
- Only show one snackbar at a time
- Don't use snackbars for critical information that requires user acknowledgment

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `message` | `string` | `''` | Notification message |
| `action-label` | `string` | `''` | Action button text |
| `leading-icon` | `string` | `''` | Icon before message |
| `open` | `boolean` | `false` | Visibility state |
| `duration` | `number` | `0` | Auto-dismiss ms (0 = manual) |

**Events:**
| Event | Description |
|-------|-------------|
| `action` | Fired when action button is clicked |
| `close` | Fired when close button is clicked |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `message` | `String` | required | Notification message |
| `actionLabel` | `String?` | `null` | Action button text |
| `onActionPressed` | `VoidCallback?` | `null` | Action handler |
| `onClosePressed` | `VoidCallback?` | `null` | Close handler |
