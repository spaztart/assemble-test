## Guidelines

- Use modals for focused tasks that require attention (confirmations, promotions)
- Keep modal content concise — avoid scrolling inside modals
- Always provide a clear way to dismiss (close button, backdrop click, or Escape key)
- Use the gradient variant sparingly for promotional content
- Place the primary action button on the right
- Avoid stacking multiple modals

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `open` | `boolean` | `false` | Whether the modal is visible |
| `header` | `string` | `''` | Header text (standard variant) |
| `body` | `string` | `''` | Body text (standard variant) |
| `gradient` | `boolean` | `false` | Use gradient background |
| `show-close` | `boolean` | `true` | Show close button |
| `barrier-dismiss` | `boolean` | `true` | Close on backdrop click |
| `aria-label` | `string` | `''` | Accessible label |

**Slots:**
| Slot | Description |
|------|-------------|
| default | Custom content (replaces header/body) |
| actions | Action buttons row |

**Events:**
| Event | Description |
|-------|-------------|
| `close` | Fired when modal is dismissed |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `child` | `Widget` | required | Content widget |
| `onClose` | `VoidCallback?` | `null` | Close handler |
| `showCloseButton` | `bool` | `true` | Show close button |
| `gradient` | `Gradient?` | `null` | Gradient background |
| `contentPadding` | `EdgeInsets` | `EdgeInsets.all(24)` | Content padding |
| `semanticLabel` | `String?` | `null` | Accessible label |
| `barrierDismissible` | `bool` | `true` | Close on backdrop tap |
