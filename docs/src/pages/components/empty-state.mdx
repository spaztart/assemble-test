# Empty State

Empty states communicate that a section has no content to display. They provide context and optional actions to help users move forward.

<div class="hero-preview">
  <asm-empty-state
    icon="inbox"
    title="No messages"
    description="When you receive messages, they'll appear here."
  ></asm-empty-state>
</div>

## With Action

Slot in a button to give users a clear next step.

<PreviewCard
  webCode={`<asm-empty-state\n  icon="add_circle"\n  title="No projects yet"\n  description="Create your first project to get started."\n>\n  <asm-button slot="action" label="Create project" start-icon="add"></asm-button>\n</asm-empty-state>`}
  flutterCode={`AsmEmptyState(\n  icon: Icons.add_circle,\n  title: 'No projects yet',\n  description: 'Create your first project to get started.',\n  action: AsmButton(\n    label: 'Create project',\n    startIcon: Icon(Icons.add),\n    onPressed: () {},\n  ),\n)`}
/>


## Without Icon

Set `show-icon` to false to hide the icon circle.

/>

## Guidelines

- Always provide a clear title explaining the empty state
- Include helpful description text suggesting what to do next
- Provide an action button when there's a clear next step
- Use relevant icons that reinforce the message
- Keep messaging positive and encouraging

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `icon` | `string` | `''` | Material Symbols icon name |
| `show-icon` | `boolean` | `true` | Whether to show the icon |
| `title` | `string` | `''` | Title text |
| `description` | `string` | `''` | Description text |
| `icon-size` | `number` | `48` | Icon size in pixels |
| `icon-background-size` | `number` | `96` | Background circle size |

**Slots:**
| Slot | Description |
|------|-------------|
| `action` | Action button(s) below the description |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `icon` | `IconData?` | `null` | Icon |
| `showIcon` | `bool` | `true` | Whether to show icon |
| `title` | `String` | required | Title text |
| `description` | `String?` | `null` | Description text |
| `action` | `Widget?` | `null` | Action widget |
| `iconSize` | `double` | `48` | Icon size |
| `iconBackgroundSize` | `double` | `96` | Background size |
