# Text Field

Text fields allow users to enter and edit text. They support multiple variants, labels, icons, validation states, and multiline input.

## Multiline (Textarea)

Set `max-lines` greater than 1 to render a textarea.

<PreviewCard
  webCode={`<asm-text-field label="Description" max-lines="4" variant="outlined"></asm-text-field>`}

/>


## Guidelines

- Always provide a label or placeholder
- Use supporting text for format hints (e.g., "MM/DD/YYYY")
- Show error messages inline below the field
- Use outlined variant for forms, filled for search and dense UIs
- Don't use placeholder text as the only label

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | Floating label text |
| `placeholder` | `string` | `''` | Placeholder text |
| `value` | `string` | `''` | Field value |
| `variant` | `outlined` \| `filled` | `outlined` | Visual variant |
| `supporting-text` | `string` | `''` | Helper text below field |
| `error-text` | `string` | `''` | Error message (triggers error state) |
| `leading-icon` | `string` | `''` | Leading icon name |
| `trailing-icon` | `string` | `''` | Trailing icon name |
| `disabled` | `boolean` | `false` | Disabled state |
| `read-only` | `boolean` | `false` | Read-only mode |
| `obscure-text` | `boolean` | `false` | Password masking |
| `max-length` | `number` | — | Max character count |
| `max-lines` | `number` | `1` | Lines (>1 = textarea) |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `label` | `String?` | `null` | Floating label |
| `placeholder` | `String?` | `null` | Placeholder text |
| `variant` | `AsmTextFieldVariant` | `.outlined` | Visual variant |
| `supportingText` | `String?` | `null` | Helper text |
| `errorText` | `String?` | `null` | Error message |
| `leadingIcon` | `IconData?` | `null` | Leading icon |
| `trailingIcon` | `IconData?` | `null` | Trailing icon |
| `enabled` | `bool` | `true` | Enabled state |
| `readOnly` | `bool` | `false` | Read-only mode |
| `obscureText` | `bool` | `false` | Password masking |
| `maxLength` | `int?` | `null` | Max characters |
| `maxLines` | `int` | `1` | Lines (>1 = multiline) |
| `onChanged` | `ValueChanged<String>?` | `null` | Change handler |
