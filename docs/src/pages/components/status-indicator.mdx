# Status Indicator

Status indicators are compact visual signals consisting of a colored dot with an optional label. They communicate the current state of an entity at a glance.

## Guidelines

- Use consistent status colors throughout the application
- Provide labels for accessibility when the dot alone is ambiguous
- Use alongside other content (e.g., in table rows or cards)
- Don't overload a view with too many status indicators

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `status` | `critical` \| `attention` \| `info` \| `muted` \| `offline` \| `positive` | `info` | Status type |
| `indicator-style` | `neutral` \| `colored` \| `inverse` | `colored` | Visual style |
| `label` | `string` | `''` | Optional label text |
| `size` | `small` \| `medium` \| `large` | `medium` | Dot size |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `status` | `AsmStatusIndicatorStatus` | required | Status type |
| `style` | `AsmStatusIndicatorStyle` | `.colored` | Visual style |
| `label` | `String?` | `null` | Optional label |
| `size` | `AsmStatusIndicatorSize` | `.medium` | Dot size |
