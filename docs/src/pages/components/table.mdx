# Table

Tables display structured data in a fixed 4-column layout with optional header, headline, and row icons. Use for presenting tabular information that benefits from alignment and scanning.

<div class="hero-preview">
  <div style="width:100%;max-width:600px">
    <asm-table id="hero-table"></asm-table>
  </div>
</div>

<script>{`
  document.addEventListener('astro:page-load', () => {
    const heroTable = document.getElementById('hero-table');
    if (heroTable) {
      heroTable.header = { col1: 'Name', col2: 'Status', col3: 'Role', col4: 'Date' };
      heroTable.rows = [
        { col1: 'Alice', col2: 'Active', col3: 'Admin', col4: '2024-01-15' },
        { col1: 'Bob', col2: 'Pending', col3: 'Editor', col4: '2024-02-20' },

    }
  });
`}</script>

## Guidelines

- Use tables for structured, scannable data with consistent columns
- Always provide column headers for clarity
- Keep cell content concise — avoid long text in table cells
- Use leading icons to add visual context to rows

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `header` | `object` | `null` | Header config: `{ col1, col2, col3, col4, headline? }` |
| `rows` | `array` | `[]` | Row data: `{ col1, col2, col3, col4, leadingIcon? }[]` |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `header` | `AsmTableHeader` | required | Column headers + optional headline |
| `rows` | `List<AsmTableRowData>` | required | Row data |
