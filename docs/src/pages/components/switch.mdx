# Switch

Switches toggle the state of a single setting on or off. They provide immediate results without requiring a form submission.

## Guidelines

- Use switches for immediate binary settings (on/off, enable/disable)
- Don't use switches when a save/submit action is required — use checkboxes instead
- Always provide a visible label alongside the switch
- Use the loading state for async operations

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `value` | `boolean` | `false` | Whether the switch is on |
| `size` | `large` \| `medium` \| `small` | `medium` | Switch size |
| `tone` | `secondary` \| `primary` | `secondary` | Color tone |
| `icon` | `string` | `''` | Icon shown when on |
| `loading` | `boolean` | `false` | Loading spinner state |
| `disabled` | `boolean` | `false` | Disabled state |
| `label` | `string` | `''` | Accessible label (aria-label) |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `value` | `bool` | required | Whether on |
| `onChanged` | `ValueChanged<bool>?` | required | Change handler. `null` disables |
| `size` | `AsmSwitchSize` | `.medium` | Switch size |
| `tone` | `AsmSwitchTone` | `.secondary` | Color tone |
| `icon` | `IconData?` | `null` | Icon when on |
| `loading` | `bool` | `false` | Loading state |
