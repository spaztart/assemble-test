# Peek Label

A small floating chip that surfaces the name of an adjacent affordance on hover or focus — commonly used alongside navigation rails or icon-only toolbars. Purely presentational; the caller handles positioning.

## Guidelines

- Use alongside icon-only navigation or toolbar items
- Appears on hover/focus of the parent element — caller controls visibility
- The label is non-interactive (`pointer-events: none`)
- Keep text short (1–2 words)
- Default size is 32px tall; small is 28px
- Elevation-5 shadow makes it float above content

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `text` | `string` | `''` | Text content |
| `size` | `'default' \| 'small'` | `'default'` | Height: 32px or 28px |
| `trailing-icon` | `string` | `''` | Optional Material icon name |
| `offline` | `boolean` | `false` | Muted/outline color |

### Flutter

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `text` | `String` | required | Chip text |
| `size` | `AsmPeekLabelSize` | `.defaultSize` | 32px or 28px |
| `trailingIcon` | `IconData?` | `null` | Optional trailing icon |
| `offline` | `bool` | `false` | Muted outline color |
