# Checkbox

Checkboxes allow users to select one or more items from a set, or toggle a single option on/off. Supports tristate (indeterminate) for parent-child selection patterns.

## States

### Checked / Unchecked

The basic checked and unchecked states.

### Tristate (Indeterminate)

When `tristate` is enabled, the checkbox cycles through three states: unchecked → checked → indeterminate.

  webCode={`<asm-checkbox label="Select all" tristate></asm-checkbox>`}

/>

## Guidelines

- Use checkboxes when users can select multiple options from a list
- Use a single checkbox for a binary choice (e.g., "Accept terms")
- Use tristate for "select all" patterns with partial selection
- Labels should be clear and positive (avoid double negatives)

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `checked` | `boolean \| null` | `false` | Checked state. `null` = indeterminate |
| `tristate` | `boolean` | `false` | Enable three-state cycling |
| `label` | `string` | `''` | Label text |
| `error` | `boolean` | `false` | Error state |
| `disabled` | `boolean` | `false` | Disabled state |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `value` | `bool?` | required | Checked state. `null` = indeterminate |
| `tristate` | `bool` | `false` | Enable three-state cycling |
| `label` | `String?` | `null` | Label text |
| `isError` | `bool` | `false` | Error state |
| `onChanged` | `ValueChanged<bool?>?` | required | Change handler. `null` disables |
