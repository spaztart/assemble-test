# Alert Banner

A compact, dismissable alert banner for short messages anchored to the top or bottom of a region. Use for informational messages with an optional action link — for example "Trial ends in 11 days" with a "View plans" action.

## Guidelines

- Keep banner titles concise — one line preferred
- Use the action link for a clear next step (e.g. "View plans", "Renew now")
- Use `neutral` for general messages, `critical` only for genuinely urgent issues
- The banner auto-wraps long text; the action link flows inline on the second line
- Always provide a close mechanism unless the banner is truly permanent

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `title` | `string` | `''` | Headline text shown right of the icon |
| `mode` | `neutral` \| `info` \| `critical` \| `positive` \| `status` | `neutral` | Visual mode controlling colors |
| `icon` | `string` | `notification_important` | Leading Material Symbols icon name |
| `action-label` | `string` | `''` | Action link text. Empty = no link |
| `show-close` | `boolean` | `true` | Whether the close button is shown |
| `close-label` | `string` | `Dismiss` | Accessible label for close button |

**Events:**
| Event | Description |
|-------|-------------|
| `action` | Fired when the action link is clicked |
| `close` | Fired when the close button is clicked |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `title` | `String` | required | Headline text |
| `mode` | `AsmAlertBannerMode` | `.neutral` | Visual mode |
| `icon` | `IconData` | `Icons.notification_important` | Leading icon |
| `actionLabel` | `String?` | `null` | Action link text |
| `onActionPressed` | `VoidCallback?` | `null` | Action handler |
| `onClosePressed` | `VoidCallback?` | `null` | Close handler. `null` hides the button |
| `closeSemanticLabel` | `String` | `'Dismiss'` | Accessible label for close |
| `semanticLabel` | `String?` | `null` | Override announced text |
