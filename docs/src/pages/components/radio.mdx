# Radio

Radio buttons allow users to select exactly one option from a set. Use when there are two or more mutually exclusive choices.

## States

### Selected / Unselected

A radio is selected when its `value` matches the `group-value`.

## Guidelines

- Always provide at least two radio options
- One option should be selected by default when possible
- Use radio buttons only for mutually exclusive selections
- For binary on/off choices, prefer a switch instead

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `value` | `string` | `''` | This radio's value |
| `group-value` | `string` | `''` | Currently selected value in the group |
| `label` | `string` | `''` | Label text |
| `disabled` | `boolean` | `false` | Disabled state |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `value` | `T` | required | This radio's value |
| `groupValue` | `T?` | required | Currently selected value in the group |
| `label` | `String?` | `null` | Label text |
| `onChanged` | `ValueChanged<T?>?` | required | Change handler. `null` disables |
