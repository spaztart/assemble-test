# Divider

Dividers are thin lines that separate content into clear groups. They help establish visual hierarchy and organize layout sections.

## Guidelines

- Use dividers to separate distinct content groups
- Avoid overusing dividers — whitespace alone is often sufficient
- Use indented dividers within lists to align with text content
- Default 1px thickness is appropriate for most cases

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `thickness` | `number` | `1` | Line thickness in pixels |
| `indent` | `number` | `0` | Leading indent in pixels |
| `end-indent` | `number` | `0` | Trailing indent in pixels |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `thickness` | `double` | `1` | Line thickness |
| `height` | `double?` | `null` | Total height including spacing |
| `indent` | `double` | `0` | Leading indent |
| `endIndent` | `double` | `0` | Trailing indent |
| `color` | `Color?` | `null` | Custom line color |
