# Split Button

Split buttons let users take a primary action or choose from a dropdown of related actions. The left side performs the default action, and the right side opens a menu.

## Guidelines

- Use the primary (left) action for the most common choice
- Keep dropdown options related to the primary action
- Pair with `asm-menu` and `asm-menu-item` for the dropdown content
- Listen to the `action` event for the primary button click
- Listen to the `toggle` event to track dropdown open/close state

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | The primary button label |
| `variant` | `filled` \| `tonal` \| `outline` | `filled` | The visual style |
| `size` | `huge` \| `spacious` \| `default` \| `compact` | `default` | The button size |
| `disabled` | `boolean` | `false` | Whether the button is disabled |
| `destructive` | `boolean` | `false` | Destructive/danger mode |
| `start-icon` | `string` | `''` | Material Symbols icon name before label |
| `open` | `boolean` | `false` | Whether the dropdown is open |

### Events

| Event | Detail | Description |
|-------|--------|-------------|
| `action` | — | Fired when the primary button is clicked |
| `toggle` | `{ open: boolean }` | Fired when the dropdown is opened or closed |
