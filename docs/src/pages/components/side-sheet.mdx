# Side Sheet

A vertical side-sheet surface that docks to the right of the main UI. A layout primitive with three optional regions: a sticky header, scrolling content, and a sticky footer. Only the content region scrolls when overflowing.

Use the `open` attribute to show/hide the sheet.

  flutterCode={`// Visibility is controlled by conditionally including\n// AsmSideSheet in the widget tree:\nif (showSideSheet)\n  SizedBox(\n    width: 280,\n    child: AsmSideSheet(\n      children: [Text('Visible content')],\n    ),\n  ),`}
/>

## Guidelines

- Use side sheets for detail panels, filters, or contextual information
- The sheet is a layout primitive — it fills its parent's height by default
- Wrap in `SizedBox` or use the `width` property to set explicit width
- Only the content region scrolls; header and footer remain sticky
- Use with `Row` layout to position alongside main content
- The 20px elevation shadow gives visual separation from the main content

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `open` | `boolean` | `true` | Whether the sheet is visible |
| `gap` | `number` | `10` | Spacing between children (px) |
| `width` | `string` | `''` | Explicit width (e.g. "320px") |
| `height` | `string` | `''` | Explicit height (defaults to 100%) |

**Slots:**
| Slot | Description |
|------|-------------|
| default | Scrolling content region |
| header | Sticky header (never scrolls) |
| footer | Sticky footer (never scrolls) |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `header` | `Widget?` | `null` | Sticky header widget |
| `children` | `List<Widget>` | `[]` | Scrolling content widgets |
| `footer` | `Widget?` | `null` | Sticky footer widget |
| `height` | `double?` | `null` | Explicit height |
| `padding` | `EdgeInsetsGeometry?` | `EdgeInsets.all(16)` | Inner padding |
| `gap` | `double` | `10` | Spacing between children |
| `backgroundColor` | `Color?` | `surfaceBright` | Background override |
| `borderRadius` | `BorderRadiusGeometry?` | `BorderRadius.circular(16)` | Corner radius |
| `boxShadow` | `List<BoxShadow>?` | elevation-5 | Shadow override |
