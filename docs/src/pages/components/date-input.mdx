# Date Input

A text input field with `MM/DD/YYYY` masking and an inline calendar picker dropdown. Supports single date and date range variants with auto-formatting, validation, and a calendar toggle for visual date selection.

## Guidelines

- Use date input for form fields where users may type or pick a date
- Always show the expected format as supporting text or placeholder
- The mask auto-inserts `/` — users only need to type digits
- Pair with the inline calendar picker for visual selection
- Use the range variant for booking flows or filter date ranges
- Validate dates against `min-date` / `max-date` constraints

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `variant` | `single` \| `range` | `single` | Input variant |
| `label` | `string` | `Date` | Label text above the field |
| `placeholder` | `string` | `MM/DD/YYYY` | Placeholder text |
| `supporting-text` | `string` | `MM/DD/YYYY` | Helper text below field |
| `value` | `string` | `''` | Date value (ISO YYYY-MM-DD) |
| `range-start` | `string` | `''` | Range start (ISO) |
| `range-end` | `string` | `''` | Range end (ISO) |
| `min-date` | `string` | `''` | Earliest selectable (ISO) |
| `max-date` | `string` | `''` | Latest selectable (ISO) |
| `disabled` | `boolean` | `false` | Disabled state |
| `error` | `boolean` | `false` | Error state |
| `error-text` | `string` | `''` | Error message |
| `end-placeholder` | `string` | `MM/DD/YYYY` | Range end placeholder |

**Events:**
| Event | Detail | Description |
|-------|--------|-------------|
| `change` | `{ value: string }` | Date changed (single) |
| `range-change` | `{ start: string, end: string }` | Range changed |
| `picker-open` | — | Calendar picker opened |
| `picker-close` | — | Calendar picker closed |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `automationIdentifier` | `String` | required | Test automation ID |
| `firstDate` | `DateTime` | required | Earliest selectable date |
| `lastDate` | `DateTime` | required | Latest selectable date |
| `label` | `String` | `'Select date'` | Header label |
| `headline` | `String` | `'Enter date'` | Bold heading text |
| `placeholder` | `String` | `'MM/DD/YYYY'` | Field placeholder |
| `value` | `DateTime?` | `null` | Current date value |
| `onChanged` | `ValueChanged<DateTime>?` | `null` | Date changed. `null` disables |
| `onConfirm` | `VoidCallback?` | `null` | OK pressed |
| `onCancel` | `VoidCallback?` | `null` | Cancel pressed |
| `onClear` | `VoidCallback?` | `null` | Clear pressed |
| `onPickerRequested` | `VoidCallback?` | `null` | Calendar icon pressed |
| `showClearButton` | `bool` | `false` | Show Clear button |
