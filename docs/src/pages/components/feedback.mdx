# Feedback

A thumbs up/down feedback widget. Use to collect quick binary sentiment on AI responses, help articles, or any content where lightweight user feedback is valuable.

## Guidelines

- Place near the content being rated
- Use a clear, concise label when provided
- The component is controlled — toggle state is managed internally
- Toggling the same button again deselects it (returns to null)
- Selected state uses tonal fill to indicate active choice

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | Optional label text |
| `value` | `'thumbs-up' \| 'thumbs-down' \| null` | `null` | Selected state |

| Event | Detail | Description |
|-------|--------|-------------|
| `thumbs-up` | `{ value }` | Fired when thumbs up is clicked |
| `thumbs-down` | `{ value }` | Fired when thumbs down is clicked |

### Flutter

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `String?` | `null` | Optional question text |
| `value` | `AsmFeedbackValue?` | `null` | Currently selected thumb |
| `onThumbsUp` | `VoidCallback?` | `null` | Thumbs up tap handler |
| `onThumbsDown` | `VoidCallback?` | `null` | Thumbs down tap handler |
