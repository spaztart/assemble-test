# Pagination

A horizontal row of pill-shaped page controls with smart windowing. When total pages exceed what fits, the middle is collapsed to an ellipsis. The current page is filled with `primary` background; other pages are transparent pills that activate on click.

<div class="hero-preview">
  <div class="preview-row">
    <asm-pagination page-count="10" current-page="5"></asm-pagination>
  </div>
</div>

<script>{`
  document.addEventListener('astro:page-load', () => {
    document.querySelectorAll('asm-pagination').forEach(p => {
      p.addEventListener('page-change', (e) => {
        p.setAttribute('current-page', e.detail.page);
      });
    });
  });
`}</script>

## Guidelines

- Use pagination for lists, tables, or feeds split across pages
- Keep sibling count reasonable (1–2) to avoid overwhelming the user
- The current page pill is non-interactive but announced as "current" for screen readers
- Previous/Next arrows disable at first/last page boundaries
- Disable the entire control when data is loading

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `page-count` | `number` | `1` | Total number of pages |
| `current-page` | `number` | `1` | Current active page (1-based) |
| `sibling-count` | `number` | `1` | Pages shown around current |
| `boundary-count` | `number` | `1` | Pages shown at start/end |
| `disabled` | `boolean` | `false` | Disable the control |
| `aria-label` | `string` | `Pagination` | Accessible label |

**Events:**
| Event | Detail | Description |
|-------|--------|-------------|
| `page-change` | `{ page: number }` | Fired when a page is selected |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `pageCount` | `int` | required | Total pages (≥ 1) |
| `currentPage` | `int` | required | Current page (1-based) |
| `onPageSelected` | `ValueChanged<int>?` | required | Page selected. `null` disables |
| `automationIdentifier` | `String` | required | Test automation ID |
| `siblingCount` | `int` | `1` | Pages around current |
| `boundaryCount` | `int` | `1` | Pages at edges |
| `semanticLabel` | `String` | `'Pagination'` | Accessible label |
