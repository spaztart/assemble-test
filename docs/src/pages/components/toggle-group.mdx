# Toggle Group

Toggle groups provide a set of mutually exclusive options presented as connected segments. Use for switching between views, filters, or modes.

      <asm-toggle-item label="Week"></asm-toggle-item>
      <asm-toggle-item label="Month"></asm-toggle-item>
    </asm-toggle-group>
  </div>
</div>

## Variants

### Page

The default pill-shaped variant for page-level navigation and mode switching.

## Guidelines

- Use 2-5 items in a toggle group
- Keep labels short (1-2 words)
- One item should always be selected
- Use page variant for top-level navigation, section variant for local filtering

## API

### Web — asm-toggle-group

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `variant` | `page` \| `section` | `page` | Visual variant |
| `size` | `xsmall` \| `small` \| `medium` \| `large` | `medium` | Group size (page variant) |
| `selected-index` | `number` | `0` | Currently selected index |
| `disabled` | `boolean` | `false` | Disabled state |

### Web — asm-toggle-item

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | Item label text |
| `start-icon` | `string` | `''` | Leading icon name |
| `end-icon` | `string` | `''` | Trailing icon name |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `items` | `List<AsmToggleItem>` | required | Toggle items |
| `selectedIndex` | `int` | `0` | Currently selected index |
| `onChanged` | `ValueChanged<int>` | required | Change handler |
| `variant` | `AsmToggleGroupVariant` | `.page` | Visual variant |
| `size` | `AsmToggleGroupSize` | `.medium` | Group size |
