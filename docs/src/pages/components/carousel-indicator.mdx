# Carousel Indicator

A row of dots indicating the current page in a carousel or onboarding flow. Purely presentational — the caller controls the active index.

## Guidelines

- Use below carousel or paged content to indicate position
- Keep the page count reasonable (3–10 dots)
- The indicator is decorative — it doesn't handle tap/swipe
- Active dot uses the primary color; inactive dots use the ghost token
- Announced as "Page X of N" for screen readers

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `count` | `number` | `1` | Total number of pages |
| `active-index` | `number` | `0` | Active page index (0-based) |

### Flutter

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `count` | `int` | required | Number of pages (must be > 0) |
| `activeIndex` | `int` | required | Index of active page [0, count) |
| `semanticLabel` | `String?` | `null` | Override "Page X of N" |
