# Accordion

Accordions display collapsible content panels for organizing and revealing information progressively. They reduce visual clutter by hiding secondary content until needed.

## Guidelines

- Use clear, descriptive titles that indicate what content is hidden
- Don't nest accordions more than one level deep
- Consider keeping the most important section expanded by default
- Use when you have 3+ sections of content that don't all need to be visible at once

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `title` | `string` | `''` | Header title text |
| `expanded` | `boolean` | `false` | Whether expanded |
| `type` | `white` \| `gray` | `white` | Background style |
| `leading-icon` | `string` | `''` | Material Symbols icon name |
| `disabled` | `boolean` | `false` | Disabled state |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `title` | `String` | required | Header title text |
| `expanded` | `bool` | `false` | Whether expanded |
| `type` | `AsmAccordionType` | `.white` | Background style |
| `leadingIcon` | `IconData?` | `null` | Leading icon |
| `child` | `Widget` | required | Expandable content |
| `onExpansionChanged` | `ValueChanged<bool>?` | `null` | Expansion handler |
