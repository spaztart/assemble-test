# Brand

The `asm-brand` component renders McAfee brand assets (logo, wordmark, or combined) as inline SVGs controlled via CSS color tokens. This ensures brand marks always match the current theme.

<div class="hero-preview">
  <div class="preview-row">
    <asm-brand variant="logo-wordmark" size="md"></asm-brand>
  </div>
</div>

## Installation

<InstallSteps

## Colors

| Color | Token | Value |
|-------|-------|-------|
| `primary` | `--md-sys-color-primary` | Black |
| `brand` | `--mcafee-color-extended-brand` | Red (#c8102e) |
| `brand-orange` | `--mcafee-color-extended-brand-orange` | Orange (#e87722) |

## Custom Height

Use the `height` property to set any custom height in pixels.

<PreviewCard
  webCode={`<asm-brand variant="logo-wordmark" color="brand" height="24"></asm-brand>\n<asm-brand variant="logo-wordmark" color="brand" height="40"></asm-brand>`}
  flutterCode={`AsmBrand(variant: AsmBrandVariant.logoWordmark, color: AsmBrandColor.brand, height: 24)\nAsmBrand(variant: AsmBrandVariant.logoWordmark, color: AsmBrandColor.brand, height: 40)`}
/>

## Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `variant` | `'logo' \| 'wordmark' \| 'logo-wordmark'` | `'logo'` | Which brand asset to render |
| `color` | `'primary' \| 'brand' \| 'brand-orange'` | `'primary'` | Color variant mapped to design tokens |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'custom'` | `'sm'` | Preset height |
| `height` | `number \| null` | `null` | Custom height in px (overrides size) |

## CSS Custom Properties

| Property | Description |
|----------|-------------|
| `--asm-brand-height` | Override height for custom sizing |
