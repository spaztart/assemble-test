# Status Notification

Status notifications are small pill-shaped badges that display a count or loading state. They overlay other elements (e.g., navigation icons) to indicate pending items.

## Guidelines

- Position overlapping the top-right corner of the related element
- Use for notification counts, unread items, or pending alerts
- Don't show "0" — hide the badge entirely when count is zero
- Use the loader status for real-time updates being fetched

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `status` | `critical` \| `attention` \| `info` \| `loader` | `info` | Status (color) |
| `count` | `number` | `0` | Count to display (>99 shows "99+") |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `status` | `AsmStatusNotificationStatus` | required | Status type |
| `count` | `int` | `0` | Count to display |
