# Menu

Menus display a list of choices on a temporary surface. They appear when users interact with a button, action, or other control.

## Density

Menus support three density levels. The menu propagates density to all child items automatically.

<PreviewCard
  webCode={`<!-- Default density -->\n<asm-menu>\n  <asm-menu-item label="Default density" start-icon="format_size"></asm-menu-item>\n  <asm-menu-item label="56px row height"></asm-menu-item>\n</asm-menu>\n\n<!-- Compact density -->\n<asm-menu density="compact">\n  <asm-menu-item label="Compact density" start-icon="compress"></asm-menu-item>\n  <asm-menu-item label="40px row height"></asm-menu-item>\n</asm-menu>`}
  flutterCode={`// Default density (56px rows)\nAsmMenu(\n  items: [\n    AsmMenuItem(\n      label: 'Default density',\n      leading: Icon(Icons.format_size),\n      automationIdentifier: 'default',\n      onPressed: () {},\n    ),\n  ],\n)\n\n// Compact density (40px rows)\nAsmMenu(\n  items: [\n    AsmMenuItem(\n      label: 'Compact density',\n      leading: Icon(Icons.compress),\n      density: AsmMenuItemDensity.compact,\n      automationIdentifier: 'compact',\n      onPressed: () {},\n    ),\n  ],\n)`}
/>


## Guidelines

- Keep menu items concise — use short labels that describe the action
- Use icons consistently — if one item has an icon, all items should
- Use `selected` to indicate current state in single-select menus
- Use supporting text sparingly for additional context
- Disable items rather than hiding them to maintain spatial consistency

## API

### asm-menu (Web)

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `density` | `default` \| `low` \| `compact` | `default` | Row density for all child items |

### asm-menu-item (Web)

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | The menu item label |
| `supporting-text` | `string` | `''` | Supporting text below label |
| `start-icon` | `string` | `''` | Material Symbols icon name (leading) |
| `end-icon` | `string` | `''` | Material Symbols icon name (trailing) |
| `selected` | `boolean` | `false` | Whether the item is selected |
| `disabled` | `boolean` | `false` | Whether the item is disabled |
| `density` | `default` \| `low` \| `compact` | `default` | Row density |

### AsmMenuItem (Flutter)

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `label` | `String` | required | Primary text label |
| `onPressed` | `VoidCallback?` | required | Tap handler. `null` disables the item |
| `automationIdentifier` | `String` | required | Stable ID for UI automation |
| `supportingText` | `String?` | `null` | Supporting text below label |
| `leading` | `Widget?` | `null` | Leading widget (icon) |
| `trailing` | `Widget?` | `null` | Trailing widget (icon) |
| `density` | `AsmMenuItemDensity` | `.defaultDensity` | Row density |
| `selected` | `bool` | `false` | Whether the item is selected |
| `semanticLabel` | `String?` | `null` | Override announced label |
