# Calendar

An inline date/date-range picker following the Figma Calendar design. Supports single-date and range selection modes, with optional action buttons and full/grid-only chrome variants.

## Guidelines

- Use the calendar for date selection where visual context matters (booking, scheduling)
- Pair with `asm-date-input` for inline editing with a dropdown picker
- Use `grid-only` chrome when embedding inside another surface
- Provide `min-date` / `max-date` to prevent invalid selections
- Use `range` mode for booking flows requiring start and end dates
- Today's date always shows a primary-colored border ring

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `mode` | `single` \| `range` | `single` | Selection mode |
| `actions` | `none` \| `cancel-ok` \| `clear-cancel-ok` | `none` | Action button row |
| `chrome` | `full` \| `grid-only` | `full` | Card chrome variant |
| `header-title` | `string` | `Select date` | Title text |
| `value` | `string` | `''` | Selected date (ISO YYYY-MM-DD) |
| `range-start` | `string` | `''` | Range start (ISO) |
| `range-end` | `string` | `''` | Range end (ISO) |
| `min-date` | `string` | `''` | Earliest selectable (ISO) |
| `max-date` | `string` | `''` | Latest selectable (ISO) |
| `confirm-label` | `string` | `OK` | Confirm button text |
| `cancel-label` | `string` | `Cancel` | Cancel button text |
| `clear-label` | `string` | `Clear` | Clear button text |

**Events:**
| Event | Detail | Description |
|-------|--------|-------------|
| `change` | `{ value: string }` | Single date selected |
| `range-change` | `{ start: string, end: string }` | Range selected |
| `confirm` | — | OK clicked |
| `cancel` | — | Cancel clicked |
| `clear` | — | Clear clicked |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `firstDate` | `DateTime` | required | Earliest selectable date |
| `lastDate` | `DateTime` | required | Latest selectable date |
| `automationIdentifier` | `String` | required | Test automation ID |
| `mode` | `AsmCalendarMode` | `.single` | Selection mode |
| `actions` | `AsmCalendarActions` | `.none` | Action buttons |
| `chrome` | `AsmCalendarChrome` | `.full` | Chrome variant |
| `initialDate` | `DateTime?` | `null` | Pre-selected date |
| `initialRange` | `DateTimeRange?` | `null` | Pre-selected range |
| `onChanged` | `ValueChanged<DateTime>?` | `null` | Date selected callback |
| `onRangeChanged` | `Function(DateTime, DateTime)?` | `null` | Range callback |
| `onConfirm` | `VoidCallback?` | `null` | OK pressed |
| `onCancel` | `VoidCallback?` | `null` | Cancel pressed |
| `onClear` | `VoidCallback?` | `null` | Clear pressed |
| `title` | `String` | `'Select date'` | Header title |
