# List Item

A feature list item row for dashboards, settings lists, and accordion bodies. Supports leading icon, overline, title, supporting text, trailing chevron, expandable content, unread dot, and badge count states.

## Expandable

Use the `expanded` slot and attribute to reveal additional content below the row.

<CodeBlock
  webCode={`<asm-list-item title="Advanced Options" expanded>\n  <asm-icon slot="leading" name="tune"></asm-icon>\n  <div slot="expanded">\n    <p>Additional settings and configuration options appear here.</p>\n  </div>\n</asm-list-item>`}
  flutterCode={`AsmListItemFeature(\n  title: 'Advanced Options',\n  leading: AsmIconContainer(icon: Icons.tune),\n  expandedSlot: Text('Additional settings appear here.'),\n  expanded: true,\n  onPressed: () => setState(() => _expanded = !_expanded),\n)`}
/>

## Guidelines

- Always provide a `title` — it's required for accessibility
- Use overline sparingly for categorization (uppercase mono style)
- Interactive rows have hover overlay, focus ring, and trailing chevron
- Read-only rows have no interaction — use for static information
- Disabled rows are dimmed to 38% opacity
- The unread dot is secondary-colored and decorative
- Badge count shows on the leading icon area (caps at 99+)
- Expanded content animates open in a surface-container panel
- Min row height is 76px with 16px border radius
- Leading slot typically holds an icon in a 40×40 container

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `title` | `string` | `''` | Primary title text |
| `overline` | `string` | `''` | Uppercase overline above title |
| `supporting-text` | `string` | `''` | Secondary line below title |
| `kind` | `'interactive' \| 'read-only'` | `'interactive'` | Interaction model |
| `state` | `'default' \| 'unread' \| 'badge'` | `'default'` | Content state |
| `badge-count` | `number` | `0` | Badge number (when state is badge) |
| `show-trailing-icon` | `boolean` | `true` | Show trailing chevron |
| `expanded` | `boolean` | `false` | Expanded slot visible |
| `disabled` | `boolean` | `false` | Disabled state |

| Slot | Description |
|------|-------------|
| `leading` | Leading content (icon, avatar) |
| (default) | Right-content area |
| `trailing` | Custom trailing widget |
| `expanded` | Expandable body content |

| Event | Description |
|-------|-------------|
| `press` | Row activated (click or Enter/Space) |

### Flutter

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `title` | `String` | required | Primary text |
| `overline` | `String?` | `null` | Uppercase overline |
| `supportingText` | `String?` | `null` | Secondary text |
| `kind` | `AsmListItemFeatureKind` | `.interactive` | Interaction model |
| `state` | `AsmListItemFeatureState` | `.defaultState` | Content state |
| `leading` | `Widget?` | `null` | Leading widget |
| `trailing` | `Widget?` | `null` | Custom trailing widget |
| `showTrailingIcon` | `bool` | `true` | Show chevron |
| `expandedSlot` | `Widget?` | `null` | Expandable content |
| `expanded` | `bool` | `false` | Expanded state |
| `onPressed` | `VoidCallback?` | `null` | Tap handler (null = disabled) |
| `rightContent` | `Widget?` | `null` | Right-aligned content |
