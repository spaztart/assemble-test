# Skeleton Loader

Skeleton loaders provide placeholder UI that mimics the shape of content while data is loading. They reduce perceived wait time and prevent layout shifts.

## Guidelines

- Match skeleton shapes to the content they replace
- Use multiple skeletons to approximate the real layout
- Animate with a shimmer to indicate loading progress
- Remove skeletons immediately when content loads — avoid artificial delays
- Use for initial page loads and lazy-loaded sections

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `shape` | `card` \| `standalone-text` \| `icon` \| `list-item` \| `neutral-shape` \| `tile` \| `button` | `neutral-shape` | Shape preset |
| `width` | `string` | — | Custom width (CSS value) |
| `height` | `string` | — | Custom height (CSS value) |
| `border-radius` | `string` | — | Custom border radius (CSS value) |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `shape` | `AsmSkeletonShape` | `.neutralShape` | Shape preset |
| `width` | `double?` | `null` | Custom width |
| `height` | `double?` | `null` | Custom height |
| `borderRadius` | `double?` | `null` | Custom border radius |
