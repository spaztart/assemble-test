# Nav Drawer

A full side-panel navigation drawer with a brand header, categorized sections, and an optional pinned footer. Uses the surfaceBright surface with elevation-5 shadow and rounded trailing corners.

</div>

<script>{`
  document.addEventListener('astro:page-load', () => {
    const trigger = document.getElementById('drawer-trigger');
    if (!trigger) return;

    let overlay = document.getElementById('drawer-overlay');
    if (overlay) overlay.remove();

    overlay = document.createElement('div');
    overlay.id = 'drawer-overlay';
    overlay.style.cssText = 'display:none; position:fixed; inset:0; z-index:9999; background:rgba(0,0,0,0.32);';

    const panel = document.createElement('div');
    panel.id = 'drawer-panel';
    panel.style.cssText = 'position:absolute; left:0; top:0; height:100%; transition:transform 0.25s ease; transform:translateX(-100%);';

    panel.innerHTML = '<asm-nav-drawer style="height:100%;"><asm-nav-section title="Security"><asm-nav-list-item label="Dashboard" icon="dashboard"></asm-nav-list-item><asm-nav-list-item label="Protection Score" icon="shield"></asm-nav-list-item><asm-nav-list-item label="Threats Blocked" icon="block"></asm-nav-list-item></asm-nav-section><asm-nav-section title="Account"><asm-nav-list-item label="My Account" icon="person"></asm-nav-list-item><asm-nav-list-item label="Subscription" icon="credit_card"></asm-nav-list-item><asm-nav-list-item label="Settings" icon="settings"></asm-nav-list-item></asm-nav-section><asm-nav-list-item slot="footer" label="Sign Out" icon="logout" show-trailing="false"></asm-nav-list-item></asm-nav-drawer>';

    overlay.appendChild(panel);
    document.body.appendChild(overlay);

    function openDrawer() {
      overlay.style.display = 'block';
      requestAnimationFrame(() => { panel.style.transform = 'translateX(0)'; });
    }
    function closeDrawer() {
      panel.style.transform = 'translateX(-100%)';
      setTimeout(() => { overlay.style.display = 'none'; }, 250);
    }
    trigger.addEventListener('click', openDrawer);
    overlay.addEventListener('click', (e) => { if (e.target === overlay) closeDrawer(); });
    document.addEventListener('keydown', (e) => { if (e.key === 'Escape' && overlay.style.display !== 'none') closeDrawer(); });
  });
`}</script>

## Nav Drawer Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `brand` | `boolean` | `true` | Show McAfee wordmark header |
| `nav-label` | `string` | `'Main navigation'` | Accessible label for the nav landmark |

## Nav Section Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `title` | `string` | `''` | Category header text (rendered uppercase mono) |

## Nav List Item Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | Row text (required) |
| `icon` | `string` | `''` | Optional leading Material icon |
| `trailing-icon` | `string` | `'arrow_forward'` | Trailing icon name |
| `show-trailing` | `boolean` | `true` | Show/hide trailing icon |
| `disabled` | `boolean` | `false` | Disabled state |
| `semantic-label` | `string` | `''` | Override accessible label |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `item-click` | `{ label: string }` | Fired when a nav list item is clicked |

## Accessibility

- The drawer renders as `<nav role="navigation">` with `aria-label`
- Category headers have `role="heading"` with `aria-level="2"`
- Sections have `role="group"` with `aria-label` matching the title
- Each list item is a `<button>` with `aria-label`
- Disabled items have `aria-disabled="true"` and `tabindex="-1"`
- Enter and Space keys activate items
- Focus is indicated with a 2px primary-color outline
