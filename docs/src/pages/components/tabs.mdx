# Tabs

Tabs organize content across different screens, data sets, and other interactions. They allow users to navigate between groups of related content.

## Variants

### Text

The default tab style with text labels only. Best for most use cases.

  webCode={`<asm-tab-group variant="text">\n  <asm-tab label="All" active></asm-tab>\n  <asm-tab label="Active"></asm-tab>\n  <asm-tab label="Completed"></asm-tab>\n</asm-tab-group>`}
  flutterCode={`AsmTabs(\n  items: [\n    AsmTabItem(\n      label: 'All',\n      automationIdentifier: 'tab-all',\n    ),\n    AsmTabItem(\n      label: 'Active',\n      automationIdentifier: 'tab-active',\n    ),\n    AsmTabItem(\n      label: 'Completed',\n      automationIdentifier: 'tab-completed',\n    ),\n  ],\n  selectedIndex: 0,\n  type: AsmTabType.text,\n  onChanged: (index) {},\n)`}

## Guidelines

- Use clear, concise labels that describe the content within each tab
- Keep the number of tabs manageable — 2 to 6 is ideal
- Don't nest tabs within tabs
- Always provide a `label` even for icon-only tabs (used as accessible name)
- In Flutter, provide `semanticLabel` for icon-only tabs for accessibility
- Use the `tab-change` event (Web) or `onChanged` callback (Flutter) to respond to tab selection

## API

### asm-tab-group (Web)

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `variant` | `text` \| `icon-horizontal` \| `icon-vertical` \| `icon` | `text` | The tab layout style |

#### Events

| Event | Detail | Description |
|-------|--------|-------------|
| `tab-change` | `{ index: number }` | Fired when the active tab changes |

### asm-tab (Web)

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | The tab label text |
| `icon` | `string` | `''` | Material Symbols icon name |
| `active` | `boolean` | `false` | Whether the tab is active |

### AsmTabs (Flutter)

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `items` | `List<AsmTabItem>` | required | List of tab items |
| `selectedIndex` | `int` | required | Index of the selected tab |
| `onChanged` | `ValueChanged<int>?` | `null` | Selection callback. `null` disables the strip |
| `type` | `AsmTabType` | `.iconLabelHorizontal` | Tab layout type |
| `showFocusIndicator` | `bool` | `true` | Show focus ring on focused tabs |

### AsmTabItem (Flutter)

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `automationIdentifier` | `String` | required | Stable ID for UI automation |
| `label` | `String?` | `null` | Tab label (required except for icon-only) |
| `icon` | `IconData?` | `null` | Tab icon (required except for text-only) |
| `showBadge` | `bool` | `false` | Show notification badge dot |
| `semanticLabel` | `String?` | `null` | Override announced label |
