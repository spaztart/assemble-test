# Topbar

A top navigation bar available in compact (mobile/tablet) and desktop variants. Supports home, back, general, and progress layouts.

## Guidelines

- Use compact topbar for mobile/tablet viewports
- Use desktop topbar for wider layouts
- Home type should show brand wordmark or logo in the brand slot
- Back type automatically shows a back arrow
- Progress type is for multi-step flows (value 0–1)
- Tiles are 48×48 with 8px radius on surface-container
- Desktop full-header supports hover/pressed state layers

## API

### Web (Compact)

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `type` | `'home' \| 'back' \| 'general' \| 'progress'` | `'home'` | Layout variant |
| `title` | `string` | `''` | Title text |
| `show-title` | `boolean` | `false` | Render the title |
| `show-left` | `boolean` | `true` | Show left tile |
| `show-right` | `boolean` | `true` | Show right tile |
| `left-icon` | `string` | varies | Left tile icon |
| `right-icon` | `string` | `'notifications'` | Right tile icon |
| `show-badge` | `boolean` | `false` | Notification badge |
| `progress` | `number` | `0` | Progress value (0–1) |

| Event | Description |
|-------|-------------|
| `left-press` | Left tile clicked |
| `right-press` | Right tile clicked |

### Web (Desktop)

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `type` | `'full-header' \| 'back-only'` | `'full-header'` | Layout variant |
| `title` | `string` | `''` | Title text |
| `sub-title` | `string` | `''` | Mono uppercase subtitle |
| `show-back` | `boolean` | `true` | Show back chevron |
| `show-icon` | `boolean` | `true` | Show leading icon tile |
| `leading-icon` | `string` | `'visibility'` | Icon in leading tile |

| Event | Description |
|-------|-------------|
| `press` | Topbar activated |

### Flutter (Compact)

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `type` | `AsmTopbarCompactType` | `.home` | Layout variant |
| `title` | `String?` | `null` | Title text |
| `showTitle` | `bool` | `false` | Render title |
| `leftIcon` | `IconData?` | varies | Left tile icon |
| `rightIcon` | `IconData` | `notifications_outlined` | Right tile icon |
| `showNotificationBadge` | `bool` | `false` | Badge on right tile |
| `progress` | `double` | `0` | Progress value |
| `onLeftPressed` | `VoidCallback?` | `null` | Left tap handler |
| `onRightPressed` | `VoidCallback?` | `null` | Right tap handler |

### Flutter (Desktop)

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `type` | `AsmTopbarDesktopType` | `.fullHeader` | Layout variant |
| `title` | `String?` | `null` | Title text |
| `subTitle` | `String?` | `null` | Mono subtitle |
| `showBack` | `bool` | `true` | Show back chevron |
| `showIcon` | `bool` | `true` | Show icon tile |
| `leadingIcon` | `IconData` | `visibility` | Leading icon |
| `onPressed` | `VoidCallback?` | `null` | Tap handler |
