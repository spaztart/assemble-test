# Navigation Rail

A vertical (or horizontal) navigation rail surface with 52×52 icon slots. Supports a brand slot, status indicators, peek labels on hover, and full keyboard navigation.

## Toggle Enablement

Items with `toggle` handle their own on/off cycle when clicked: offline (muted dot) → loading spinner → active (info dot). Click again to reverse. Try clicking the VPN item below.

## Navigation Rail Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `orientation` | `'vertical' \| 'horizontal'` | `'vertical'` | Rail layout direction |
| `brand` | `boolean` | `false` | Show McAfee brand slot |
| `brand-interactive` | `boolean` | `false` | Make brand slot a button |
| `brand-active` | `boolean` | `false` | Brand slot is active destination |
| `brand-label` | `string` | `'McAfee'` | Accessible label for brand slot |

## Rail Item Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | Visible label and accessible name |
| `semantic-label` | `string` | `''` | Override accessible name |
| `icon` | `string` | `''` | Material Symbols icon name |
| `active` | `boolean` | `false` | Selected/active state |
| `disabled` | `boolean` | `false` | Disabled state |
| `status` | `string` | `''` | Status indicator dot (`critical`, `info`, `muted`, etc.) |
| `toggle` | `boolean` | `false` | Toggle on/off behaviour (self-managed cycle on click) |
| `toggle-duration` | `number` | `1500` | Loading duration in ms for toggle cycle |
| `loading` | `boolean` | `false` | Loading state (shows spinner badge) |
| `show-peek` | `boolean` | `true` | Show peek label on hover |
| `peek-position` | `'right' \| 'top'` | `'right'` | Peek label direction (right for vertical, top for horizontal) |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `brand-click` | — | Fired when interactive brand slot is clicked |
| `item-click` | `{ label: string }` | Fired when a non-toggle rail item is clicked |
| `toggle-start` | `{ label, turning }` | Fired when a toggle item begins its loading cycle |
| `toggle-end` | `{ label, active }` | Fired when a toggle item completes its cycle |

## Accessibility

- The rail renders as `<nav role="navigation">` with `aria-label`
- Each item is a `<button>` with `aria-label`, `aria-current="page"` when active
- Disabled items have `aria-disabled="true"` and `tabindex="-1"`
- Enter and Space keys activate items
- Focus is indicated with a 2px primary-color outline
