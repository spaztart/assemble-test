# Chat Bubble

A chat message bubble with asymmetric border radius. The notched top-right corner reads as the bubble's "tail" and identifies the sender. Pass `text` for a simple message, or use the default slot for custom content.

  </div>
</div>

## With Custom Content

Use the default slot for composing icons, images, or rich content. Children are laid out in a horizontal row with 10px gap.

<PreviewCard
  webCode={`<asm-chat-bubble>\n  <asm-icon name="smart_toy" style="font-size: 20px;"></asm-icon>\n  <span>I'm your AI assistant</span>\n</asm-chat-bubble>\n\n<asm-chat-bubble>\n  <asm-icon name="attachment" style="font-size: 20px;"></asm-icon>\n  <span>document.pdf</span>\n</asm-chat-bubble>`}
  flutterCode={`AsmChatBubble(\n  children: [\n    Icon(Icons.smart_toy, size: 20),\n    Text('I\\'m your AI assistant'),\n  ],\n)\n\nAsmChatBubble(\n  children: [\n    Icon(Icons.attachment, size: 20),\n    Text('document.pdf'),\n  ],\n)`}
/>

## Guidelines

- Use chat bubbles for conversational UI (chatbots, support, messaging)
- Keep messages concise for readability
- The asymmetric radius (16px / 4px) provides visual direction — the 4px "tail" corner identifies the sender
- Use the slot for richer content like file attachments, images, or icons
- Don't use both `text` and slot content — they are mutually exclusive

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `text` | `string` | `''` | Simple text message content |

**Slots:**
| Slot | Description |
|------|-------------|
| default | Custom content (icons, text, images). Used when `text` is empty |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `text` | `String?` | `null` | Simple text message |
| `children` | `List<Widget>?` | `null` | Custom content widgets (mutually exclusive with text) |
