## Guidelines

- Use the loader for inline loading (buttons, inputs, cards, nav items)
- Always provide semantic labels for accessibility
- Respect reduced-motion preferences — the spinner pauses automatically
- Avoid multiple loaders in close proximity

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `size` | `number` | `40` | Width and height of the spinner in pixels |
| `variant` | `'bar'` | `'bar'` | Visual style |
| `stroke-width` | `number` | `3` | Stroke thickness |
| `aria-label` | `string` | `'Loading'` | Accessible label |

### Flutter

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `size` | `double` | `40` | Outer dimension |
| `style` | `AsmLoaderStyle` | `.bar` | Visual style (bar or halfTrack) |
| `strokeWidth` | `double` | `3` | Stroke thickness |
| `foregroundColor` | `Color?` | `secondary` | Arc color |
| `trackColor` | `Color?` | `ghost` | Track color |
| `duration` | `Duration` | `1100ms` | Full rotation duration |
| `semanticLabel` | `String` | `'Loading'` | Screen-reader label |
