# Badge

Badges are compact status indicators that convey severity, counts, or categorical information. They support multiple statuses and visual types for flexible communication.

## Guidelines

- Use badges for status, severity, or category labels
- Keep label text short (1-2 words)
- Use consistent status colors across the application
- Don't overload a single view with too many badges

## API

### Web

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `label` | `string` | `''` | Badge label text |
| `status` | `high` \| `moderate` \| `low` \| `neutral` \| `dismissed` \| `stat` \| `offline` | `neutral` | Severity status |
| `type` | `primary` \| `secondary` \| `tertiary` | `primary` | Visual emphasis type |
| `icon` | `string` | `''` | Material Symbols icon name |
| `number` | `number` | `0` | Numeric count display |
| `dot-position` | `string` | `''` | Position for dot indicator |

### Flutter

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `label` | `String` | required | Badge label text |
| `status` | `AsmBadgeStatus` | `.neutral` | Severity status |
| `type` | `AsmBadgeType` | `.primary` | Visual emphasis type |
| `icon` | `IconData?` | `null` | Leading icon |
| `number` | `int?` | `null` | Numeric count |
